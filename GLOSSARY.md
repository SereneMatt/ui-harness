# UI Harness

Shared language for inspecting responsive interfaces across multiple screen sizes.

## Language

**Target application**:
The running website being inspected in the harness.

**Viewport**:
A view of the target application at a specified layout width and height. Its displayed scale can change without changing those layout dimensions.
_Avoid_: Device emulator

**Workspace**:
The inspection surface containing the selected viewports for a target application.

**UI inspection**:
Visual and interactive examination of the target application to identify interface problems across viewport sizes.
_Avoid_: Automated test suite
