## Agent skills

### Issue tracker

Issues and specs live as local Markdown under `.scratch/<feature>/`. Before reading or writing tickets, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage roles as local issue statuses. Before triaging, read `docs/agents/triage-labels.md`.

### Domain docs

This repo uses a single-context layout: root `GLOSSARY.md` and `docs/adr/`. Before exploring the codebase, read `docs/agents/domain.md`.
